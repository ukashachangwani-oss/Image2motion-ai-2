Publish in 3 steps
  1. Read and edit the draft. Add your own experience, screenshots or examples.
  2. On GitHub open the posts folder → Add file → Create new file, paste the file name and the text.
  3. Click Commit. Vercel rebuilds automatically and the post goes live in about a minute.

Tip: set a future date: in the post to schedule it. It appears on the first deploy on or after that date.
